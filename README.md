A deadpan one-star review of gravity for make.fun's "One-Star Review of
Something Essential": a single line of at most 160 characters, a real
complaint filed in earnest against a thing that cannot be fixed.

> Gravity: keeps everything down, including my phone, my keys, and my mood. No off switch, no refund, and it has been doing this since forever.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–160 characters), writes it to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set), and reads it back to verify the
bytes match. The output is the same on every run.
